# CHECKON - Система контроля посещаемости по QR-кодам

## Описание
Система для отметки посещаемости студентов через QR-коды с автоматическими уведомлениями родителям. Поддерживает три роли: администратор, преподаватель и ученик.

## Функционал
- ✅ Управление студентами (CRUD)
- ✅ Управление расписанием (CRUD)
- ✅ Генерация QR-кодов для занятий
- ✅ Сканирование через камеру телефона
- ✅ Автоопределение опозданий
- ✅ Email уведомления родителям
- ✅ Панель преподавателя в реальном времени (обновление каждые 15 сек)
- ✅ Отчёты и экспорт в Excel
- ✅ Регистрация новых пользователей
- ✅ Управление пользователями (админ)
- ✅ Повышение/понижение ролей пользователей
- ✅ Тёмная тема оформления

## Роли пользователей

### Администратор
- Полный доступ ко всем функциям системы
- Управление пользователями (создание, удаление, изменение ролей)
- Управление студентами
- Управление расписанием
- Просмотр всех отчётов и уведомлений

### Преподаватель
- Управление студентами
- Управление расписанием
- Генерация QR-кодов для занятий
- Просмотр посещаемости
- Просмотр отчётов
- Просмотр уведомлений

### Ученик
- Отметка посещаемости через QR-код
- Просмотр расписания на сегодня

## Технологии
- PHP 8+
- SQLite
- Bootstrap 5
- HTML5 QR Code Scanner
- Chart.js

## Установка
1. Склонируйте репозиторий
2. Запустите локальный сервер (Например: XAMPP, PHP Built-in Server)
3. Откройте `http://127.0.0.1:8080`
4. База данных создастся автоматически при первом запуске

## Регистрация
- Новые пользователи могут зарегистрироваться через форму регистрации
- При регистрации создаётся аккаунт ученика
- Для получения роли преподавателя или администратора необходимо обратиться к администратору

## Структура базы данных

### Таблицы
- `users` - пользователи системы (логин, пароль, ФИО, роль, student_id)
- `students` - студенты (ФИО, группа, email родителя, телефон)
- `schedule` - расписание (дисциплина, преподаватель, аудитория, день недели, время)
- `qr_codes` - QR-коды (schedule_id, дата, токен)
- `active_sessions` - активные сессии QR (schedule_id, qr_code_id, токен, время действия)
- `attendance` - посещаемость (student_id, schedule_id, qr_code_id, время отметки, статус)
- `notifications_log` - лог уведомлений (student_id, attendance_id, дата отправки, статус)

## Распределение задач

### Backend
- `students.php` - управление студентами
- `schedule.php` - управление расписанием
- `generate_qr.php` - генерация QR-кодов
- `users.php` - управление пользователями
- `login.php` - авторизация и регистрация
- `logout.php` - выход из системы
- `init.php` - инициализация БД
- `config.php` - конфигурация
- `functions.php` - вспомогательные функции

### Frontend
- `navbar.php` - единая панель навигации
- Все стили CSS (тёмная тема)
- Адаптивный дизайн для мобильных устройств

### Fullstack
- `scan.php` - сканирование QR-кодов (ученик)
- `teacher_panel.php` - панель преподавателя
- `admin_panel.php` - панель администратора
- `notifications.php` - лог уведомлений
- `phpqrcode.php` - генерация QR-кодов

### QA
- `attendance.php` - журнал посещаемости
- `reports.php` - отчёты и статистика
- `error.php` - страница ошибок
- Тестирование всех модулей системы
